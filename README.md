# STAR GACHA — iPhone向け個人用ガチャ

## 機能
- 女優名・レアリティ（SSR/SR/R/N）・メモの追加、編集、削除
- レアリティごとの排出確率設定（合計100%で抽選）
- 抽選履歴
- JSONバックアップ・復元
- Safari向けレスポンシブUI

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成（例: `star-gacha`）。
2. `index.html` をリポジトリ直下にアップロードしてコミット。
3. リポジトリの **Settings → Pages** を開く。
4. **Build and deployment** で **Deploy from a branch** を選択。
5. Branch を `main`、フォルダを `/(root)` にして **Save**。
6. 数分待ち、表示される `https://ユーザー名.github.io/star-gacha/` をSafariで開く。
7. Safariの共有ボタン → **ホーム画面に追加**。

## データ保存について
データは開いたブラウザの localStorage に保存されます。SafariのWebサイトデータ削除や端末変更で失われる可能性があるため、アプリ内の「バックアップ」からJSONを保存し、必要に応じて「バックアップを復元」を使ってください。ブラウザのプライベートブラウズは避けてください。

## 確率の仕様
SSR/SR/R/N の設定合計が100%のときに抽選できます。抽選されたレアリティの登録者が0人の場合は、登録済み全員から選び、その人物に設定されたレアリティを表示します。レアリティ別の母集団がある場合、その中から均等に1人を選びます。

このアプリは静的なクライアントサイドアプリです。GitHub Pagesで公開するとURLを知る人がアクセスできます。機密情報は入力しないでください。
